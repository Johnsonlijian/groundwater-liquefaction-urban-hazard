# Figure Design Brief

## Figure Set Role

The suite turns the manuscript from a data-audit look into an argument surface:
water-management trajectories alter a hidden groundwater state variable inside
a static liquefaction screen, producing bounded regional review classes.

## Figure 1

- Role: hero mechanism and framework.
- Takeaway: observed storage trajectories update the water-table state variable;
  the output is a local review cue.
- Object: urban basin, aquifer, water table, susceptible sediments, monitoring
  wells and published liquefaction-screen term.
- Driver: groundwater recovery/recharge or depletion.
- Mechanism: storage trend -> Delta WTD via S_y -> water-table coefficient ->
  Delta P_liq screening increment -> A/B/C/D review class.
- Boundary: schematic 3D geometry; not site-scale hazard prediction.
- Export: Blender `.blend` if Blender is available, plus SVG/PDF/PNG/PPTX.

## Figures 2-6 and Box 1

- Figure 2: global null and regional payload.
- Figure 3: regional evidence cards.
- Figure 4: product-consensus evidence ladder.
- Figure 5: aquifer-context S_y phase diagram.
- Figure 6: engineering context and event-boundary check.
- Box 1: seven-step non-regulatory review protocol.

## Guardrails

No generative-AI raster image is used as final publication evidence. Numerical
labels are read from project tables. Colors encode direction and evidence class
with labels/shapes, not color alone.
